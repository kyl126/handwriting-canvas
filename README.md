# 手写笔迹 · 多色画布

一个纯前端的手写笔迹工具，支持全屏手写、多色画笔、笔迹平滑、静态/滚动预览、全屏展示与图片复制。无需后端，打开即用。

![预览截图](preview.png) <!-- 建议替换为你的实际截图 -->

## ✨ 功能特性

- **全屏手写**：在宽大的画布上手写，支持鼠标与触摸（手指/触控笔）。
- **多色画笔**：内置 7 种预设颜色，也可用取色器自定义任意颜色。
- **粗细调节**：画笔与橡皮共用一个粗细滑块，实时生效。
- **橡皮擦**：点击擦除整笔，支持连续擦除。
- **撤销 / 清空**：随时撤销上一笔或一键清空。
- **笔迹平滑**：提供「关 / 弱 / 中 / 强」四档平滑，采用移动平均 + 二次贝塞尔曲线，让线条更连贯自然。
- **智能提示**：全屏手写时，屏幕中央显示提示文字；一旦开始书写即自动隐藏，画布清空后重新出现，不干扰书写。
- **内容保留**：全屏手写完成后再次进入，不会自动清空，方便继续修改。
- **静态预览**：笔迹生成后以图片形式居中展示。
- **滚动预览**：笔迹以跑马灯形式循环滚动，速度可调（2–20 秒）。
- **全屏预览**：支持静态 / 滚动两种模式切换；静态模式下可拖拽平移、滚轮/按钮缩放、双击重置。
- **复制图片**：一键将生成的笔迹图片复制到剪贴板（PNG 格式）。
- **响应式**：横屏小高度时自动全屏展示预览，适配移动端。
- **纯前端**：无依赖、无后端，单个 HTML 文件即可运行。
